1. ภาพรวมระบบและสถาปัตยกรรม (System Overview)

VibePost คือแพลตฟอร์มบริหารจัดการเนื้อหาและโพสต์โซเชียลมีเดียอัตโนมัติแบบครบวงจร ที่ผสานขุมพลังปัญญาประดิษฐ์ (Generative AI) ชั้นนำระดับโลก เพื่อช่วยให้ธุรกิจสามารถวางแผน สร้างสรรค์ และกระจายคอนเทนต์ไปยังเพจและช่องทางต่าง ๆ ได้อย่างรวดเร็วและเป็นระบบ

🌟 จุดเด่นหลักของระบบ

  • Multi-Workspace Isolation: แยกบริหารจัดการข้อมูล แบรนด์ ทีมงาน คีย์ AI และเพจโซเชียลของแต่ละธุรกิจอย่างเป็นอิสระ ปลอดภัย 100%
  • 3-in-1 Adaptive Text Engine: พิมพ์หัวข้อหรือบรีฟสั้นเพียงครั้งเดียว AI สร้างเนื้อหาพร้อมกัน 3 รูปแบบ (Long-form, Social Caption, AIDA Marketing)
  • Multi-Model Visual Studio: สร้างรูปภาพและคลิปวิดีโอคุณภาพสูงผ่าน Google Gemini Imagen 4.0, Google Veo, Luma Dream Machine และ Kling AI พร้อมระบบสำรองรูป/วิดีโออัตโนมัติ (Fallback Protection)
  • Flexible Publishing Pipelines: รองรับทั้งการโพสต์ด่วนทันที (1-Click Fast Track), การตุนคอนเทนต์ลงคลังแบบร่าง (Batch Staging), และการปรับแต่งขั้นสูง (Multi-Channel Wizard)
  • Auto-Publisher Cron Engine: ระบบตั้งเวลาปล่อยโพสต์ตามกำหนดการโดยไม่ต้องเฝ้าหน้าจอ
  • Real-Time Token & Cost Analytics: ติดตามปริมาณการใช้ Token และประเมินค่าใช้จ่ายหน่วย USD แปลงเป็นเงินบาท (THB) แบบเรียลไทม์

🔄 แผนภาพกระบวนการทำงานแบบ End-to-End

[บรีฟ/หัวข้อ] ➔ [AI Studio: แคปชัน 3 สไตล์ + รูปภาพ/วิดีโอ]
      │
      ├── Route A (ด่วน): ปุ่ม '🚀 เผยแพร่ทันที / ตั้งเวลา' ➔ เข้าคิว Auto-Post
      ├── Route B (ตุนสต็อก): ปุ่ม '💾 บันทึกเป็นแบบร่าง' ➔ เก็บใน Drafts Queue
      └── Route C (ปรับแต่งลึก): ปุ่ม '⚙️ เปิดใน AI Publisher' ➔ Wizard 4 ขั้นตอน
      │
[Auto-Publisher Cron] ➔ [ยิง Graph API ไปยัง Facebook / Instagram] ➔ [Monitor & History]

2. ขั้นตอนที่ 1: การตั้งค่าบัญชีและการเชื่อมต่อ (Workspace & Setup)

ก่อนเริ่มต้นสร้างเนื้อหา ทีมงานจำเป็นต้องตรวจสอบและตั้งค่าพื้นฐานในระบบ 2 ส่วน ได้แก่ การเชื่อมต่อโซเชียลมีเดีย และการใส่คีย์สมองกล AI

2.1 การจัดการพื้นที่ทำงาน (Workspaces)

  • เมนู Workspaces ช่วยให้สามารถสลับการทำงานระหว่างแบรนด์หรือลูกค้าแต่ละเจ้าได้ทันที
  • สมาชิกแต่ละคนจะมีบทบาท (Role) ที่ชัดเจน:
  • 🔑 Admin: มีสิทธิ์สูงสุดในการตั้งค่าคีย์ API, จัดการสมาชิก และเชื่อมต่อช่องทาง
  • 👤 Member: สามารถสร้างคอนเทนต์ ใช้งาน AI Studio และสั่งโพสต์ได้
  • 👁️ Viewer: ดูรายงานและปฏิทินโพสต์ได้อย่างเดียว

2.2 การเชื่อมต่อเพจโซเชียลมีเดีย (Social Integrations)

  1. ไปที่เมนู Integrations (จัดการช่องทาง) ในแถบด้านซ้าย
  2. คลิกปุ่ม "เชื่อมต่อ Facebook / Instagram"
  3. ระบบจะเปิดหน้าต่างยืนยันสิทธิ์ ให้ล็อกอินและเลือกเพจที่ต้องการมอบหมายให้ VibePost ดูแล
  4. ตรวจสอบว่าสถานะของเพจขึ้นเป็น Active (เชื่อมต่อแล้ว)

2.3 การตั้งค่าคีย์ปัญญาประดิษฐ์ (AI API Keys)

ไปที่เมนู Settings (ตั้งค่า) เพื่อตรวจสอบหรือกรอกคีย์ผู้ให้บริการ AI:

  • Workspace Configuration Summary: แผงควบคุมด้านบนจะแสดง Badge เขียวเมื่อระบบพร้อมใช้งาน
  • Google Gemini (แนะนำอย่างยิ่ง):
  • สมัครรับคีย์ฟรีหรือแบบชำระเงินที่ Google AI Studio
  • นำคีย์มากรอกในช่อง Google Gemini
  • ประโยชน์: คีย์ชุดนี้ชุดเดียวรองรับทั้งการเขียนเนื้อหา (Gemini 2.5), การเจนรูปภาพ (Imagen 4.0 Fast) และการสร้างวิดีโอ (Google Veo 2.0)
  • Kling AI Video (สำหรับวิดีโอความคมชัดสูง):
  • การกรอกคีย์ Kling ต้องระบุในรูปแบบ AccessKey:SecretKey (คั่นด้วยเครื่องหมายโคลอน : เช่น ak_12345:sk_67890)
  • ระบบหลังบ้านจะนำไปสร้าง JWT Token เพื่อติดต่อเซิร์ฟเวอร์สิงคโปร์ให้อัตโนมัติ
  • Luma Dream Machine: กรอก Bearer API Key จากบัญชี Luma
  • Moonshot / Kimi AI: กรอกคีย์สำหรับโมเดลภาษาที่เก่งภาษาไทยและภาษาจีนเป็นพิเศษ
  • ความปลอดภัย: คีย์ทั้งหมดจะถูกเข้ารหัสลับ (Encrypted) ก่อนบันทึกลงฐานข้อมูล PostgreSQL

3. ขั้นตอนที่ 2: การสร้างสรรค์เนื้อหาใน AI Studio (Content Production)

หน้า AI Studio (/dashboard/ai-studio) คือห้องทำงานหลักของครีเอเตอร์ในการเปลี่ยนไอเดียให้กลายเป็นโพสต์พร้อมใช้

3.1 การสร้างข้อความแคปชัน (3-in-1 Adaptive Text Engine)

  1. ในช่อง "หัวข้อคอนเทนต์ / บรีฟสินค้า" ให้พิมพ์สิ่งที่ต้องการสื่อสาร เช่น:

> "เปิดตัวเซรั่มบำรุงผิวหน้าสูตรไฮยาเข้มข้น ลดเลือนริ้วรอยใน 7 วัน โปรโมชั่นซื้อ 1 แถม 1 เฉพาะสัปดาห์นี้"

  1. คลิกปุ่ม "✨ สร้างเนื้อหา 3 สไตล์"
  2. ระบบจะแสดงผลลัพธ์ 3 แท็บให้เลือกใช้งาน:
  3. 📄 บทความยาว (Long-form): เนื้อหาเชิงลึก อธิบายรายละเอียด เหมาะสำหรับโพสต์บล็อกหรือบทความความรู้
  4. 📱 โซเชียลแคปชัน (Social Caption): กระชับ มีการเว้นวรรคให้อ่านง่าย ติดแฮชแท็ก (#) และอีโมจิพร้อมดึงดูดสายตา
  5. 🎯 เชิงการตลาด (Marketing AIDA): เขียนตามหลักจิตวิทยาการขาย (Attention - ความสนใจ, Interest - จุดเด่น, Desire - ความอยากได้, Action - กระตุ้นให้สั่งซื้อ)
  6. ผู้ใช้สามารถคลิกแก้ไขข้อความในกล่องได้โดยตรง

3.2 การสร้างรูปภาพประกอบ (AI Image Creator)

  1. เลื่อนลงมาที่ส่วน สร้างรูปภาพประกอบ (AI Visual)
  2. คลิกปุ่ม "ดึงบรีฟจากแคปชัน" เพื่อให้ AI ถอดใจความสำคัญมาสร้างเป็น Prompt รูปภาพ หรือพิมพ์ระบุสิ่งที่ต้องการ
  3. สามารถเลือกสไตล์ เช่น Photorealistic, Minimal, Cinematic, 3D Render
  4. คลิก "🎨 สร้างรูปภาพ (Generate Image)"

5. ระบบป้องกันความผิดพลาด (Fail-Safe Fallback):

  • ระบบจะสร้างผ่าน Gemini Imagen 4.0 Fast เป็นอันดับแรก
  • หากโควตา API เต็ม หรือเครือข่ายมีปัญหา ระบบจะดึงภาพสต็อกความละเอียดสูงที่ตรงกับหมวดหมู่ผ่าน LoremFlickr มาทดแทนให้ทันที หน้าเว็บจะไม่เกิดข้อผิดพลาด

3.3 การสร้างคลิปวิดีโอ (AI Video Studio)

  1. เลื่อนไปที่แท็บ สร้างวิดีโอ (Video Studio)
  2. ระบุการเคลื่อนไหวหรือฉากที่ต้องการ เช่น "กล้องแพนช้าๆ เผยให้เห็นหยดเซรั่มกระทบผิวน้ำ มีแสงแดดยามเช้าส่องประกาย ละเอียดระดับ 4K"
  3. สามารถนำรูปภาพที่เจนไว้มาเป็น Image Reference / Character Seed เพื่อคุมโทนภาพได้
  4. คลิก "🎬 สร้างคลิปวิดีโอ (Generate Video)"

5. ลำดับการประมวลผลวิดีโอ (Cascade Pipeline):

  • ลำดับที่ 1: Google Veo 2.0 (ผ่าน Gemini Key)
  • ลำดับที่ 2: Luma Dream Machine
  • ลำดับที่ 3: Kling AI
  • ลำดับที่ 4: Pexels Curated Video (หากไม่มีคีย์หรือการเจนไม่สำเร็จ จะดึงคลิปสต็อกพรีเมียมมาใส่ให้ทันที)

4. ขั้นตอนที่ 3: เส้นทางการเผยแพร่ 3 รูปแบบ (3 Action Routes)

เมื่อได้แคปชันและรูปภาพ/วิดีโอเรียบร้อยแล้ว VibePost ให้ความยืดหยุ่นในการทำงานด้วย 3 เส้นทาง:

🚀 Route A: โพสต์ด่วนทันที (1-Click Fast Track)

  • เหมาะสำหรับ: คอนเทนต์เกาะกระแส ข่าวสารด่วน หรือโพสต์ประจำวันที่ต้องการความรวดเร็ว
  • วิธีทำ:
  • คลิกปุ่มสีน้ำเงิน "🚀 เผยแพร่ทันที / ตั้งเวลา Auto-Post"
  • จะมี Modal พรีวิวหน้าฟีดโซเชียลจำลองปรากฏขึ้น
  • ติ๊กเลือกเพจ Facebook หรือ Instagram ที่ต้องการโพสต์
  • เลือกโหมด:
  • ⚡ โพสต์ทันที (Post Now): ยิงขึ้นเพจทันที
  • 📅 ตั้งเวลา (Schedule): กำหนดวันและเวลาที่ต้องการล่วงหน้า

5. กดยืนยัน โพสต์จะถูกนำเข้าคิวระบบ Auto-Publisher ทันที

💾 Route B: การเก็บตุนแบบร่าง (Batch Staging Mode)

  • เหมาะสำหรับ: ครีเอเตอร์ที่ต้องการวางแผนคอนเทนต์ล่วงหน้าเป็นรายสัปดาห์หรือรายเดือน (ตุนไว้ทีละ 10-30 โพสต์)
  • วิธีทำ:
  • คลิกปุ่มสีเขียว "💾 บันทึกเป็นแบบร่าง (Save Draft)"
  • โพสต์จะถูกบันทึกสถานะเป็น DRAFT และถูกส่งไปเก็บไว้ที่ "คลังแบบร่างรอโพสต์ (Drafts Queue)"
  • ทีมงานสามารถสร้างโพสต์ถัดไปได้ทันทีโดยไม่ต้องผูกเพจหรือกำหนดเวลาในขณะนั้น

⚙️ Route C: วิซาร์ดปรับแต่งขั้นสูง (Multi-Channel Wizard)

  • เหมาะสำหรับ: แคมเปญขนาดใหญ่ที่ต้องการปรับแต่งข้อความของแต่ละช่องทางให้แตกต่างกัน
  • วิธีทำ:
  • คลิกปุ่ม "เปิดใน AI Publisher (ขั้นสูง)"
  • ระบบจะส่งข้อมูลผ่าน Session Storage Bridge เข้าสู่กระบวนการ 4 ขั้นตอน:
  • สเต็ป 1: เลือกแพลตฟอร์มปลายทาง
  • สเต็ป 2: ปรับแต่งข้อความแยกตามช่องทาง (เช่น ข้อความยาวสำหรับ Facebook, สั้นกระชับสำหรับ Instagram)
  • สเต็ป 3: ตรวจสอบพรีวิวแยกอุปกรณ์ (มือถือ / เดสก์ท็อป)
  • สเต็ป 4: กำหนดเวลาและยืนยันการเผยแพร่

5. ขั้นตอนที่ 4: การบริหารจัดการคลังแบบร่าง (Staged Drafts Queue)

เมื่อบันทึกแบบร่างไว้ในระบบแล้ว การนำคอนเทนต์มาใช้งานทำได้ดังนี้:

  1. ไปที่เมนู Post History (ประวัติโพสต์ & คลังเนื้อหา)
  2. คลิกแท็บ "📝 คลังแบบร่างรอโพสต์ (Drafts Queue)"
  3. บนหน้าจอจะแสดงการ์ดของทุกคอนเทนต์ที่ถูกสร้างไว้ พร้อมรูปภาพ/วิดีโอตัวอย่าง และข้อความสรุป
  4. เครื่องมือบนแต่ละการ์ด:
  5. [ 🚀 ตั้งค่า & สั่งโพสต์ ]: คลิกเพื่อเปิด Modal สั่งเลือกเพจและกำหนดเวลาปล่อยโพสต์ได้ทันที
  6. [ ✏️ แก้ไข ]: เปิดเข้าสู่ตัวแก้ไขเพื่อปรับปรุงคำหรือเปลี่ยนภาพประกอบ
  7. [ 🗑️ ลบ ]: ย้ายแบบร่างที่ไม่ต้องการลงในถังขยะ (Trash)

6. ขั้นตอนที่ 5: การติดตามผลและตรวจสอบค่าใช้จ่าย (Monitor & Analytics)

6.1 การดูคิวงานและปฏิทินโพสต์ (Post Monitor)

  • เข้าเมนู Post Monitor (/dashboard/monitor)
  • ตรวจสอบตารางปฏิทินแสดงโพสต์ตามวันและเวลา
  • มีแถบสถานะแยกสีชัดเจน:
  • 🟡 SCHEDULED: โพสต์ที่ตั้งเวลาไว้และรอ Cron ดึงไปเผยแพร่
  • 🔵 PUBLISHING: กำลังส่งข้อมูลไปยังเซิร์ฟเวอร์โซเชียลมีเดีย
  • 🟢 PUBLISHED: โพสต์ขึ้นสู่ช่องทางโซเชียลมีเดียเรียบร้อยแล้ว
  • 🔴 FAILED: เกิดข้อผิดพลาด พร้อมแสดง Error Log จาก Graph API

6.2 การตรวจสอบ Token และค่าใช้จ่าย AI (Usage & Cost Tracking)

  • เข้าเมนู Post History (/dashboard/history)
  • ดูการ์ด AI Usage Summary ด้านบนสุด:
  • แสดงจำนวน Token รวมที่ใช้งานแยกตามค่าย (Gemini, Moonshot, Luma, Kling)
  • ประเมินค่าใช้จ่ายสะสมเป็นเงินดอลลาร์สหรัฐ (USD)

7. ขั้นตอนที่ 6: การแก้ไขปัญหาเบื้องต้น (Troubleshooting Guide)

อาการที่พบ สาเหตุที่เป็นไปได้ วิธีแก้ไข
สั่งสร้างรูปภาพหรือวิดีโอแล้วระบบหมุนค้างหรือไม่ตอบสนอง 1. คีย์ API ที่ระบุใน Settings ไม่ถูกต้องหรือวงเงินหมด<br>2. เซิร์ฟเวอร์ผู้ให้บริการ AI มีผู้ใช้งานหนาแน่น 1. เข้าไปที่หน้า Settings ตรวจสอบว่ามีแถบแจ้งเตือนสีแดงหรือไม่<br>2. ลองนำคีย์ Gemini หรือ Luma ใหม่มาทดสอบบันทึกอีกครั้ง
ภาพที่ได้เป็นภาพสต็อกทั่วไป ไม่ใช่รูปที่วาดจาก AI เป็นกลไก Fail-Safe Fallback ทำงานเมื่อระบบฟรีติดคิว หรือชนลิมิต IP ของโฮสต์ ไม่จำเป็นต้องแก้ไข เป็นระบบป้องกันไม่ให้กระบวนการหยุดชะงัก หากต้องการภาพ AI คมชัดตลอดเวลา แนะนำให้ใส่คีย์ Google Gemini ใน Settings
โพสต์ไม่ขึ้น Facebook/IG ตามเวลาที่กำหนด (สถานะ FAILED) 1. Access Token ของเพจหมดอายุ (Facebook บังคับต่ออายุตามรอบความปลอดภัย)<br>2. ระบบ Cron หลังบ้านติดขัด 1. ไปที่หน้า History ค้นหาการ์ดสีแดง แล้วอ่านข้อความ Error ใต้การ์ด<br>2. หากเกิดจาก Token ให้ไปที่เมนู Integrations แล้วกด Reconnect เพจใหม่อีกครั้ง
เปิดหน้าต่าง Wizard แล้วข้อความหรือรูปภาพไม่แสดง เบราว์เซอร์อาจเปิดโหมด Incognito หรือปิดกั้นการจัดเก็บ Session Storage รีเฟรชหน้าเบราว์เซอร์ และตรวจสอบว่าการตั้งค่าเบราว์เซอร์อนุญาตให้จัดเก็บข้อมูล Local/Session Storage

8. คู่มือการนำเข้าเอกสารสู่ Google Docs

เอกสารคู่มือนี้ถูกจัดเตรียมไว้ให้อยู่ในฟอร์แมตที่สามารถนำไปใช้งานบน Google Docs ได้ทันทีผ่าน 3 วิธีง่าย ๆ:

🔹 วิธีที่ 1: อัปโหลดไฟล์ Word (.docx) เข้า Google Drive (แนะนำ สวยงามที่สุด 100%)

  1. ดาวน์โหลดไฟล์ VibePost_Training_Manual.docx จากปุ่มดาวน์โหลดในระบบ
  2. เปิดเว็บเบราว์เซอร์ไปที่ Google Drive
  3. ลากไฟล์ .docx ไปวางในโฟลเดอร์ Google Drive ของท่าน
  4. ดับเบิลคลิกเปิดไฟล์ แล้วเลือก "เปิดด้วย Google เอกสาร (Open with Google Docs)"

5. เอกสารจะถูกแปลงเป็น Google Doc สมบูรณ์แบบ พร้อมหัวข้อ ตาราง สีสัน และสารบัญ

🔹 วิธีที่ 2: ใช้ฟังก์ชันคัดลอกในระบบเว็บ (1-Click Copy)

  1. ไปที่หน้าคู่มือในระบบ VibePost (/dashboard/manual)
  2. คลิกปุ่ม "📋 คัดลอกเนื้อหาทั้งหมด (Copy for Google Docs)" ที่แถบเครื่องมือด้านบน
  3. เปิดแท็บใหม่ไปที่ docs.new เพื่อสร้างเอกสารใหม่
  4. กดแป้นพิมพ์ Ctrl + V (หรือ Cmd + V บน Mac) เพื่อวางเนื้อหาลงในเอกสารได้ทันที
